# numoo — concept site

Static prototype of the numoo charity platform: verified education cases, curated item auctions,
and the money trail behind both. Operated by [charity name]; numoo is the technology platform.

All cases, lots and figures are fictional. No payments are taken.

- Plain HTML/CSS/JS, no build step. Every page shares `assets/numoo.css` and `assets/numoo.js`.
- Deployed on Vercel from the `main` branch.
